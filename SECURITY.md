# Report a security issue

Email **support@inboxpip.com** with a short description and steps to reproduce. Do not post credentials, access tokens, private email contents or another person's data in a public issue. We will coordinate a private exchange if more information is needed.

This repository contains connection configuration and workflow instructions. The hosted InboxPip service has separate authorization and account controls. Never commit an InboxPip API key, an email password or an exported client credential file to this repository.

If a key is accidentally exposed, revoke it in the InboxPip dashboard. Removing it from the latest file does not remove copies from Git history or other people's machines.
